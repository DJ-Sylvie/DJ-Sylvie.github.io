Ideas

So far, I have played eight games for inspiration:

  1. Generic Fighter Maybe
  2. Your Only Move Is HUSTLE
  3. Voices of the Void
  4. EGGNOGG+
  5. Adrorium
  6. Inventory
  7. Diskophoros
  8. Deltarune

Aside from Inventory and Deltarune, these games have all been played on Itch.io. Inventory was played on Twine, and while Deltarune could be played on Itch, I used Steam. I've played many other games, but these games were more actively thought over.

The main problem for me is that I don't want to make a low-quality game, but I effectively don't know how to code a game in any coding languages aside from blocks.

From what I understand, there are ways to get around this by using more simplistic coding platforms, including but not limited to:

  • Twine
  • RPG Maker
  • Pygame
  • Microsoft MakeCode Arcade
  • Scratch
  • (potentially) PICO-8
